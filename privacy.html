Privacy

This page describes the current prototype. The AGENT MVP stores prototype-created agents and install choices locally in your browser unless a future connected service explicitly states otherwise.

Current prototype

The current AGENT MVP is a front-end prototype. It does not provide production account infrastructure, payment processing, or autonomous device access.

Local browser data

Prototype settings may be saved with browser local storage so the demo can remember created agents and installed capabilities on that device. You can clear that data through the app’s reset control or browser storage controls.

Future connected services

When production integrations are added, each connection should clearly identify what data is accessed, why it is needed, what actions are permitted, and how access can be revoked.

User control

The intended product principle is that permissions, memory, and sensitive actions remain visible and controllable by the user.

Contact

Before public commercial launch, this policy should be updated with the operating company’s legal name, contact information, data processors, retention practices, and jurisdiction-specific disclosures.
